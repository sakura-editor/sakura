# 功能对照表（Sakura Editor for Mac）

本表是阶段 0 第 6、7 步的产物：列出原版的全部命令和主要的非命令功能，标注在 Mac 版中的处理方式和优先级。完整数据见 [feature-matrix.csv](feature-matrix.csv)（UTF-8，可用 Excel 或 Numbers 打开）。

> 当前是**初稿**：分类和优先级是根据源码自动生成并人工调整的，需要项目负责人审阅确认。

## 字段说明

- **分类**
  - 直接移植：命令逻辑在原版核心代码里，可以复用，只需接到新界面。
  - 需要改造：依赖 Windows 机制或需要重做界面，功能本身可以实现。
  - 沙盒下不可行：受 App Store 沙盒或平台限制，App Store 版做不到。
- **优先级**
  - MVP：阶段 2 最小可上架版本必须具备。
  - 追平：阶段 3 补齐。
  - 可选：视需求和精力决定是否实现。
- 命令的“编号”“命令名”来自 `sakura_core/Funccode_x.hsrc`，“中文名”来自原版的中文语言包，语言包没有的由人工补译。

## 沙盒下不可行的功能

| 命令名 | 功能 | 原因与替代方案 |

## 如何重新生成

源码中的命令有增减时，可以重新生成命令部分（分类规则写在脚本里）：

```sh
python3 macos/tools/parse_funccode.py sakura_core/Funccode_x.hsrc sakura_lang/sakura_rc_zh-CN.rc > /tmp/rows.json
python3 macos/tools/build_feature_matrix.py /tmp/rows.json macos/docs
```
